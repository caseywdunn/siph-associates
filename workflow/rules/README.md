# Analysis rule files

The [workflow audit guide](../../docs/workflow/README.md) links a descriptive
README for **every `.smk` file in this directory**. Each guide explains the
biological purpose, inputs, outputs, rules and interpretation limits, and embeds
a rule graph generated by Snakemake with matching preview/launch commands.

The files remain in their original locations so documentation changes do not
alter analysis dependencies. Start with the index for the full data flow, or
open `docs/workflow/<rule-file-stem>/README.md` for a particular file.
